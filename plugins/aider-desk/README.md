# AiderDesk extension — Build Remote Agent

Copy this folder to `~/.aider-desk/extensions/gbr-pair` (user install, not a core AiderDesk PR).

Requires `gbr-agent run` so `http://127.0.0.1:8788` answers. Tools: `gbr-status`, `gbr-inject`.

The phone still only sees **terminal windows** on this PC. The AiderDesk Electron UI is not a TTY; it will not show up in the app roster.
