---
description: Pair Build Remote Agent phone to this desktop session (gbr/1)
---

Install `gbr-agent` v0.6.0+, then:

```
gbr-agent pair
gbr-agent run
```

Phone: Scan the PC QR (or type the 8-char code). Attach `http://127.0.0.1:8788` or `gbr-mcp`. Phone is spectator.

Docs: https://grokbuildremote.com/integrations.html
